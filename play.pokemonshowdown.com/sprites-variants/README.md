# PokéRogue shiny variant sprites

Rare (`rare/`, `rare-back/`) and Epic (`epic/`, `epic-back/`) shiny variants, named by Showdown species ID (`-f` = female), plus the normal (`normal/`) and shiny (`shiny/`) sprites of Pokémon that only PokéRogue has. `variants.js` lists which exist and their sizes.

Made by `build-tools/build-shiny-variants`; don't edit by hand.

Sprites from [PokéRogue](https://pokerogue.net) ([GitHub](https://github.com/pagefaultgames/pokerogue)), via Sandstormer's [PokeRogue SearchDex](https://github.com/Sandstormer/PokeRogue-Dex). All rights to the sprites stay with their original creators.
